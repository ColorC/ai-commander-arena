# 演出规范 v0（沙盘按台本演）

目标：解说说到哪，画面就演到哪。每句台词播出时，画面都在表现这句话说的事：
- 镜头对准它说的地方、它说的时刻。
- 它点名的单位亮起来。
- 它提到的数字、命令或行为在画面上看得见。

台本是 `$ARENA_DATA/video/program/live-commentary/<场>.md`，按「第 N 段｜到 HH:MM」分段，每段若干句「Claude：…」「GPT：…」。
每场的输入都在 `$ARENA_DATA/video/program/staging/manifest.json`：台本、逐段日志、原始会话与事件、游戏数据、中文番号表、事实清单。

## 一、画面底子（统一，不用逐镜头写）

**常驻只有两样**：
- 战场时钟（游戏内时间 HH:MM）。
- 字幕。

份额、兵力、命令、射击线、目标格分值、箭头都**不常驻**，只在镜头要的时候出现，镜头结束就收起。

**兵牌**用原版兵牌，只留核心：
- 国别底色。
- 剪影或 NATO 图标。
- 状态小圆点。
- 移动时边角的方向三角。

英文番号和字母（T/W/L、A/M/S/H、编制点）一律不画。

**中文番号**写在兵牌下方的小标签里，默认只写名字（如「Y连6排」「28团2营坦克连」）：
- 标签只给两类单位：镜头里被点名或高亮的单位，以及近景时焦点附近的单位。
- 中远景不在焦点里的单位只留兵牌，不写名字。
- 一格叠多张兵牌时，只标一次「××等 N 个」。

**其余单位**在有高亮时整体压暗。

**目标格**用原版 VP 徽章：
- 平时只显示归属色。
- 镜头要讲分值时，才在徽章上出分值。
- 易手只换颜色，不加特效。

**数字和文字**：
- 坐标写 (列,行)，单位写中文简称（来自 names 表的 short）。
- 画面上不复述字幕已经说的话。
- 不放解释性小字。

## 二、镜头（shot）

一个镜头配一句或连续几句讲同一件事的台词。每句台词恰好属于一个镜头。

```json
{
  "id": "F03-2",
  "lines": [2, 3],
  "shows": "Y连6排被打到失去战斗力，(17,16) 易手给红军",
  "time": { "from": "04:44", "to": "04:52" },
  "focus": { "hex": "(17,16)" },
  "zoom": "close",
  "cues": [ ... ]
}
```

| 字段 | 含义 |
|---|---|
| `lines` | 本段台词的序号，从 0 起，按 .md 里本段的顺序 |
| `shows` | 一句话写观众该看到什么，必须是台词说的那件事 |
| `time` | `{"at": "HH:MM"}` 停在这一刻；`{"from", "to"}` 在台词期间把战斗从 from 播到 to（跨度大就是快进） |
| `focus` | 镜头对准哪里，四种写法之一：`{"hex": "(c,r)"}`、`{"hexes": [...]}`（框住几格）、`{"units": [代码...]}`（框住这些单位）、`{"view": "whole"}`（全图） |
| `zoom` | `close` 近景（几个格，看得清兵牌和名字）、`mid` 中景（一片战区）、`wide` 远景（大半张图） |

时间选台词说的那一刻或那一段。讲一段时间的累积（「这半小时丢了 67 个子单位」），就用 from–to 播出来，并配合 `losses` 计数。

## 三、按需信息（cue）

每个 cue 都可以带 `"on": <台词序号>`，表示从这句台词开始出现（默认是镜头第一句）；出现后持续到镜头结束。
单位一律写**单位代码**，也就是游戏数据里的原名，日志里括号中的那个，如 `"6 Y Coy"`、`"3/2/28"`、`"1/1/21 Gds MRR"`。

| type | 字段 | 画面（统一画法） |
|---|---|---|
| `highlight` | `units` | 这些单位加原版黄色选中框、写中文名，其余单位压暗 |
| `tag` | `units`、`show`: [`strength` 兵力 剩/满, `losses` 本镜头内损失, `order` 当前命令(中文), `morale` 士气, `ammo` 弹药, `readiness` 准备度, `delay` 命令延迟, `subunits` 子单位数, `equipment` 装备] | 名字标签后面接出这些属性的小条；不要的不出 |
| `order` | `units`，可选 `issued`、`effective`（HH:MM）、`label` | 画这些单位当时的命令：移动画原版青色路径和箭头，炮击画火力线到目标格；写中文命令名；给了 issued/effective 就标「hh:mm 下令 → hh:mm 生效」 |
| `fire` | 可选 `units`、`side`（`blue`/`red`）、`window` [from, to] | 只画这些单位（或这一方）在窗口内的射击线、命中和炮击效果；不写就是本镜头时间内所有射击 |
| `losses` | `units` 或 `side`、可选 `window` | 被打的单位冒「−n」，角落累计「红军 −67」 |
| `hex` | `hexes`，`mark`: `objective`/`area`/`point`，可选 `label` | 目标格出徽章和分值；`area` 是一片格子的轮廓；`point` 是单格描边。label 只写名字或分值，不写句子 |
| `score` | `show`: `share`/`strength`/`both` | 屏幕上方出双方份额或兵力的读数，变化时数字滚动，镜头结束收起 |
| `fog` | `view`: `blue`/`red` | 只显示这一方看得到的敌人（问号牌、大类牌、看清的剪影），用来讲「看不到」 |
| `card` | `kind`: `order`/`quote`，`side`，`time`，`text` | 指挥官原话卡；text 必须是会话或日志里的原话，不改写，不重复字幕 |

## 四、设计时怎么做

1. 逐段读日志（manifest 里的 `segments[].log`），一句一句对台词。台词说的单位、时刻、格子，要在日志或数据里找到实据。
2. 找不到实据的说法（泛泛的评论、预测），就给它最能代表那句话的画面。例如讲「东边是血肉磨盘」，就快进那片战区，再加 `fire` 和 `losses`。不要硬塞不相干的东西。
3. 两个相邻镜头焦点相同时，不切镜头，只换 cue。连续几句都在讲一个地方，就放进一个镜头，按 `on` 逐步加信息。
4. 每个镜头同时出现的按需信息尽量不超过三样，画面要一眼看懂。
5. 写完跑校验，直到 `ok: true`：

   ```
   python -I -X utf8 tools/video/staging/staging_check.py <staging json>
   ```

## 五、交付

每场一个 `$ARENA_DATA/video/program/staging/<场>.json`：

```json
{
  "case": "F",
  "segments": [ { "seg": 1, "shots": [ ... ] }, ... ],
  "notes": "需要渲染端新增的能力、数据里查不到的说法"
}
```

另附一份 `<场>.md`：逐段列「台词 → 镜头 → 画面上看到什么」，给人看。
